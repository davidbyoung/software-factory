# Commands run for you

The commands skills, hooks, and workflows run, not you. They are listed
so nothing lunamill does is hidden. The commands a person runs are in
[Commands](cli.md).

## Tickets

Skills call these to read or change a ticket. Every one goes through one
interface, which is what lets another ticket system be added later:
[Developing](../developing.md#adding-a-ticket-system) explains it. Each exits
non-zero with the error when it cannot reach the ticket system: a failed
read is never an empty answer. `view` and `list` take `--json`, which
prints what the ticket system returned as one JSON value. `edit`,
`comment`, and `open` refuse a body with a bare tag-like `<word>` the
ticket system would swallow, name it, and post nothing.

N is the ticket's key as your ticket system writes it, such as `12`
([GitHub Issues](../integrations/github-issues.md#what-lunamill-can-and-cannot-do-there)
says how it writes one).

| `lunamill ticket repositories N`                            | Prints the repositories N names, each ✓ set up or ✗ with what to do, or the one line that says where N builds. Exits 1 with a ✗                                                                                                                                                                                                                             |

| `lunamill ticket adopt N...`                                | Adds the lunamill label to each ticket named. `--all-open` labels every open ticket instead, and `--since-lock FILE` labels only when FILE, the `.claude/lunamill.lock` an update replaces, has no [`tickets.labels.lunamill`](settings/tickets.md#ticketslabels). | `lunamill pr follow-ups --event FILE`                       | Opens a ticket for each follow-up that was ticked when the pull request in FILE, the event the code host sent, merged, and that has none yet                                                                                                                                                                                                                |

A command that records something on a ticket, such as `claim`,
`refining`, `cost`, `open`, or `adopt`, then starts the board sync, so the
board follows it. When it cannot start it, it says so on a line of its
own and still exits 0, and the nightly sync catches up:

```text
? the board updates at the nightly sync: couldn't start the board sync (HTTP 403: Resource not accessible by integration)
```

`lunamill ticket refined N` posts nothing and exits 1 when N's body lacks a
section a build reads, printing one line for each, such as
`missing: ## Acceptance criteria`. With `--check` it prints `sound` for a
body that passes. [Your own skills and agents](../customize/plugins.md#refiner) lists the sections.

## Pull requests

Pull requests stay on the code host whatever the ticket system. A pull
request's conversation comments and labels go through these, never the
ticket system.

| Command                                           | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lunamill pr state [N]`                           | What stands between N and a merge: checks, review, threads, conflict                                                                                                                                                                                                                                                                                                                                                                                |
| `lunamill pr threads N`                           | The unresolved review threads, each with its comments. `--all` lists the resolved ones too                                                                                                                                                                                                                                                                                                                                                          |
| `lunamill pr reply N COMMENT --body-file FILE`    | Replies on a thread                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `lunamill pr resolve N COMMENT`                   | Resolves a thread                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `lunamill pr closes N`                            | The tickets N closes, by key                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `lunamill pr cost N`                              | Notes what this session spent on pull request N since it started                                                                                                                                                                                                                                                                                                                                                                                    |
| `lunamill pr for-branch BRANCH`                   | The newest pull request from BRANCH, open or not: `#N open`, `#N merged`, or `#N closed`, or `none` when there has been none                                                                                                                                                                                                                                                                                                                        |
| `lunamill pr wait-checks N`                       | Waits for every CI run on the pushed commit. Prints `success`, `failure:` with the failed checks, or `no checks`                                                                                                                                                                                                                                                                                                                                    |
| `lunamill pr ready N`                             | Marks a draft ready for review. When `commit.gpgsign` is `true`, refuses while the code host shows a commit as not verified                                                                                                                                                                                                                                                                                                                         |
| `lunamill pr comments N`                          | N's conversation comments: ID, author, time, and first line. `--author LOGIN`, `--contains TEXT`, `--from-approvers`, which keeps the comments whose author can write to the repository, and `--json`, which prints each comment's `id`, `user.login`, `body`, and `created_at`                                                                                                                                                                     |
| `lunamill pr comment N --body-file FILE`          | Posts a conversation comment and prints its ID. | `lunamill pr comment-view ID`                     | Prints one conversation comment's body                                                                                                                                                                                                                                                                                                                                                                                                              |
| `lunamill pr label N --add LABEL`                 | Adds a label to N. `--remove LABEL` takes one off                                                                                                                                                                                                                                                                                                                                                                                                   | . Refuses `verdict-override` and `policy-override`, which only a person adds |
| `lunamill pr watch N`                             | Waits until N needs attention, says why, and exits                                                                                                                                                                                                                                                                                                                                                                                                  |
| `lunamill pr watch N --release`                   | Stops watching N                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `lunamill pr review-pending N REVIEW`             | Exits 0 when an approver's review has something of theirs to answer, and 1, saying why, when it has not                                                                                                                                                                                                                                                                                                                                             |
| `lunamill pr conflicts`                           | The pull requests the conflict sweep takes, one number a line; exits 0 when there is one and 1 when none                                                                                                                                                                                                                                                                                                                                            |
| `lunamill pr open --title TITLE --body-file FILE` | Opens a draft pull request from the current branch into the default branch and prints its number. `--base BRANCH` names another base, and `--ready` opens it ready for review. Fails in the code host's own words when the branch has nothing new or already has one open                                                                                                                                                                           |
| `lunamill pr view N --field FIELD`                | Prints one field of N: `head` (its last commit, in full), `branch`, `base`, `title`, `body`, `state`, or `mergeable` (`dirty` for a conflict, `unknown` until the code host has worked it out)                                                                                                                                                                                                                                                      |
| `lunamill pr review N REVIEW`                     | One review as JSON: its author, its body, and each comment it left on a line, with the comment a reply replies to                                                                                                                                                                                                                                                                                                                                   |
| `lunamill pr push`                                | Pushes this branch, or, in a session in the cloud, hands its commits over to be checked and pushed. Never the default branch                                                                                                                                                                                                                                                                                                                        |
| `lunamill pr pull`                                | Merges the remote's commits on this branch. A session in the cloud already has the newest there were when it started                                                                                                                                                                                                                                                                                                                                |
| `lunamill pr unverified N`                        | Each of N's commits the code host does not show as signed, with the reason. | `lunamill pr uncovered [BASE] [LCOV]`             | The lines the branch added or changed that the coverage report shows no test covers, a file at a time: `MISS` for a line no test ran, and `PART` for a line that ran with a branch never taken. `BASE` is what the branch is compared with, and is the default branch on your repository's remote, usually `origin`, when left out. `LCOV` is the report, and is `coverage/lcov.info` when left out. Prints nothing when every such line is covered |
| `lunamill pr failed N`                            | For N's last commit, the failures `wait-checks` counts: each failed job's name and the last 200 lines of its log, from the newest run of each workflow started by a push or a pull request, and what a check that did not pass wrote about itself. | `lunamill pr review-again N`                      | Asks for a fresh review of N's last commit. | `lunamill deps --any`                             | Exits 0 when a dependency pull request is open and 1 when none is                                                                                                                                                                                                                                                                                                                                                                                   |

`lunamill pr wait-checks N` waits until the code host
shows the commit you pushed as N's head, then until the newest run of each
CI job started by that push or pull request has finished. It leaves out
lunamill's own jobs, so a failed board sync does not stop a pull
request being marked ready. With no run two minutes after the commit became the head, it
prints `no checks` and exits 0. A failure exits 3.

**In a session in the cloud,** these and the ticket commands work from what
was handed over: a read answers from it, a write prints `Asked:` and is done
after the session ends, and `pr wait-checks`, `pr watch`, and
`pr state --wait` say that the run ends there
([What a cloud run is](../security/cloud-runs.md#what-a-cloud-run-is)).

Where [`pr-review`](settings/pr-review.md#pr-review) is off, no automated
review runs. `lunamill pr state N` then prints
`Claude review: none expected on this head`, and `lunamill pr state N --wait`
and `lunamill pr watch N` wait for none.
